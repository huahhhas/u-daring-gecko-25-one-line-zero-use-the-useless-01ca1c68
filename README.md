One hilariously useless superpower in a single line: the power to teleport anywhere in the world, with the small catch that it only works to the spot you're already standing on — and only on Tuesdays. `main.py` holds the line behind a 200-character gate and writes it, exactly as-is, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
